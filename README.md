# SyrMura AI — Render

Бастапқы Flask дизайны мен HTML/CSS беттерін сақтайтын Render нұсқасы.

## Render-ге орналастыру

1. Осы қалтаның ішіндегі барлық файлды GitHub репозиторийінің түбіріне жүктеңіз.
2. Render ішінде **New Web Service** таңдаңыз.
3. GitHub репозиторийін қосыңыз.
4. Render `Dockerfile` файлын автоматты анықтайды.
5. **Deploy Web Service** батырмасын басыңыз.

OCR үшін қазақ, орыс, араб және ағылшын Tesseract тілдері Docker контейнерінде орнатылады.

## Ескерту

Тегін Render қызметінде SQLite дерекқоры мен жүктелген файлдар қайта орналастыру кезінде тұрақты сақталмауы мүмкін. Тұрақты өндірістік нұсқада PostgreSQL және сыртқы файл сақтау қызметін қосқан дұрыс.
